RULE BUDDY
==========

Ask questions about the rulebook in plain English and get an answer that
cites the section and page it came from.


HOW TO START IT
---------------

1. Copy the folder "Rule Buddy" from this drive onto your computer -- the
   Desktop is fine. It will run from the drive too, but slower.

2. Open that folder and double-click "Rule Buddy" (the open-book icon).

That is all. Nothing to install. Windows only.

The first time, Windows may say "Windows protected your PC" because the
program is not signed. Click "More info", then "Run anyway".


HOW TO USE IT
-------------

Type a question and press Ask. Answers come back with markers like
[#412 p.87] -- click one to read the exact excerpt the answer was drawn
from, so you can check the book yourself.

Questions work best in the book's own words. Try "cover ranged attack"
rather than "can I shoot someone who is hiding".

  New question   starts a fresh thread.
  Ask more       keeps the current thread and answers using everything
                 found so far.

The book "Exalted Third Edition" is already indexed and loaded. You do
not need the PDF.


IF SOMETHING GOES WRONG
-----------------------

"The rulebook index is missing"
    The books folder, with the .db index inside it, must sit next to
    Rule Buddy.exe. Copy the whole folder again, all of it together.

"The API returned 401" or "no API key"
    The key in config.json has stopped working. Ask whoever gave you this drive for a new one.
    You can still search and read sections without it; you just will not
    get written answers.

"The request failed"
    No internet connection, or the connection dropped. Try again.

Nothing happens when I double-click
    Make sure you copied the whole "Rule Buddy" folder, including the
    "_internal" folder next to the exe. The program will not start without it.


A NOTE ON THE KEY
-----------------

config.json in the program folder holds an Anthropic API key that pays
for the written answers. Please do not share the folder or the key with
anyone else, and let whoever gave you the drive know when you are done with it.
